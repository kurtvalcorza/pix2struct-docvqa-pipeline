# Pix2Struct DocVQA-base document question answering pipeline

DIMER inference and bounded-adaptation wrapper for **Pix2Struct fine-tuned on DocVQA** (`google/pix2struct-docvqa-base`), pinned to an immutable Hugging Face revision and loaded only from a digest-verified local snapshot. Inference renders a question above one page and returns generated answer text; adaptation trains only the final decoder blocks on validated page/question/answer records, selects by validation ANLS, and exports a digest-bound safetensors adapter.

## Upstream alignment

- Model: `google/pix2struct-docvqa-base`
- Revision: `63f6b3de436e39f75c7a486881a9c2c14a7f4e89`
- Upstream weight license: Apache-2.0
- Upstream task: visual question answering over document images (DocVQA)
- Repository adaptation: final two of twelve decoder blocks by default; all other parameters remain frozen

## Quick start

```python
from PIL import Image
from pix2struct_docvqa_pipeline import Pix2StructDocVQAPipeline, anls

pipe = Pix2StructDocVQAPipeline.from_pretrained()        # stages + verifies weights/pix2struct-docvqa-base first
result = pipe.answer(Image.open("invoice.png"), "What is the invoice number?")
print(result["answer"], result["new_tokens"], result["truncated"])   # generated text; no score exists

# score against an accepted answer you know (DocVQA's ANLS metric)
print(anls(result["answer"], ["NW-2026-0417"]))

# bounded E2E adaptation and reload
from pix2struct_docvqa_pipeline.samples import build_sample_dataset
splits = build_sample_dataset()
pipe.adapt(splits["train"], splits["validation"], epochs=2)
artifact = pipe.save_artifact("outputs/pix2struct_docvqa_adapter")
again = Pix2StructDocVQAPipeline.from_artifact(artifact)
```

Install into a Python 3.12 environment that already holds the pinned dependencies with `pip install -e . --no-deps`; run `pytest -q -o addopts= tests` for the offline test suite (no weights needed). On a fresh clone the manifest is committed but the weights are not: `Pix2StructDocVQAPipeline.from_pretrained(allow_download=True)` fetches exactly the missing manifest-listed files at the pinned revision, then verifies them.

`pytorch_model.bin` exists upstream and is deliberately not listed (pickle; DIMER does not accept `.bin`).

## Input, adaptation, and artifact contracts

`answer` retains the existing ceilings: image sides 16..4096 px, question length 1..256 characters, `max_new_tokens` 1..128 (default 32), greedy decoding, and at most 2,048 patches. `validate_dataset` accepts 8..5,000 `{id, document_id, image, question, answers}` mappings and refuses malformed or duplicate rows. `adapt(..., epochs=3, lr=2e-4, batch_size=1, trainable_decoder_layers=2)` trains only complete final decoder blocks and keeps the highest-validation-ANLS epoch. `evaluate` reports ANLS and exact match; `save_artifact` and `from_artifact` write/load `adapter.safetensors` only after verifying the base identity, base-weight digest, artifact digest, and exact tensor set. The default CC0 synthetic corpus is fixed at 72/18/30 question rows across document-disjoint train/validation/test splits.
